# RSA暗号体験

ブラウザでRSA暗号の「鍵生成」→「暗号化」→「復号」まで体験することができるWebアプリケーションです。

## 概要

このアプリケーションは、RSA暗号の基本的な仕組みを理解するための教育用ツールです。公開鍵暗号方式の代表的なアルゴリズムであるRSA暗号を、視覚的にわかりやすく学ぶことができます。

## 機能

### 1. 鍵生成
- 素数 p, q の選択
- 公開鍵（n, e）の生成
- 秘密鍵（p, q, d）の生成

### 2. 暗号化
- ポケベル暗号を使った平文の入力
- 公開鍵を使った暗号化処理
- 暗号化された数値の表示

### 3. 復号
- 暗号文の入力
- 秘密鍵を使った復号処理
- 復号された文字列の表示

## 使い方

1. **ペアで「受信者」「送信者」の役割を決める**
2. **受信者**: 「鍵生成」ページで秘密鍵と公開鍵を作成
3. **受信者**: 公開鍵を送信者に渡す
4. **送信者**: 「暗号化」ページで平文を入力し、公開鍵で暗号化
5. **送信者**: 暗号文を受信者に渡す
6. **受信者**: 「復号」ページで暗号文を秘密鍵で復号

## GitHub Pagesでの公開

このアプリケーションは完全に静的なHTML/CSS/JavaScriptで構築されており、GitHub Pagesで公開できます。

### 公開方法

1. GitHubリポジトリの Settings → Pages に移動
2. Source を "Deploy from a branch" に設定
3. Branch を選択（例: `main` または `gh-pages`）
4. Save をクリック

数分後、`https://<username>.github.io/<repository-name>/` でアクセスできるようになります。

## ポケベル暗号について

便宜上、文字の数値化にポケベル暗号を使用しています。本来のRSA暗号では文字コード（ASCII、UTF-8など）を使用しますが、教育目的のため、より視覚的にわかりやすいポケベル暗号を採用しています。

## 注意事項

- このアプリケーションは教育目的で作成されています
- 実際のセキュリティ用途には使用しないでください
- 小さな素数を使用しているため、暗号強度は低いです
